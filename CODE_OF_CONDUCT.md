# Code of Conduct

Deft is a small, mostly-solo project today. As we grow we want it to stay a place people enjoy contributing to. The bar here is simple:

## Be respectful

Treat people in issues, PRs, and discussions the way you'd want to be treated in a code review at work. Disagree about code; don't make it personal.

## Be patient

Many contributors are working on this in their evenings or weekends. Reviews and replies may take days. Bumping a thread once is fine; pressuring isn't.

## Be specific

When you report a bug, file a feature request, or push back on a PR — bring concrete details (steps, file paths, screenshots, version). Vague complaints don't move anyone forward.

## Out of bounds

The following will get a comment removed and, if repeated, a ban:

- Personal attacks, slurs, or harassment
- Sustained derailing of issues or PRs
- Posting other people's private information (email, IP, real name, employer) without consent
- Spam or commercial promotion in issues, PRs, or discussions

## Reporting

If you see something that violates this, email **conduct@deft.ing**. We aim to reply within 3 business days. We'll keep your report confidential to the extent that resolving the situation allows. Maintainers are also subject to this code — feel free to report us too.

## Scope

This applies to anywhere Deft's community happens: GitHub issues/PRs/discussions, official chat channels, project events, and direct contact about Deft project work.
