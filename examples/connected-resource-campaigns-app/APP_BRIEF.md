# Connected Resource Campaigns

This is the Phase 5 connected upgrade of the Phase 4 Resource Campaigns App.
It keeps the same App and Module lineage, adds one compatible plain-text body
field, depends on the independent Resource Contacts App, and exposes one
reviewed sandbox-email action through App Protocol v1.

The action is intentionally narrow: one Campaign, one related Contact, one
explicit approval, and one governed App Run. It does not provide scheduling,
bulk delivery, automation, or an App-authored runtime.
