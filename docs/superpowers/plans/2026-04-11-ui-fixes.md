**File:** `apps/web/src/app/(app)/agent/page.tsx`

The employee tab currently shows a "coming soon" placeholder. Replace it with a functional chat interface — a text input that sends messages to the agent streaming endpoint with `agent_employee_id` in the body.

- [ ] Find the `activeEmployee` branch (where `activeTab !== 'defty'` and `activeEmployee` exists)
- [ ] Replace the placeholder with: employee header (avatar + name + role) + message list (initially empty) + composer input

- [ ] The simplest approach: when employee tab is active, render the same `AgentChat` component but pass `agentEmployeeId` prop, which gets included in the message POST body
